Credit Card Fraud Detection

A machine learning project that detects fraudulent credit card transactions using an XGBoost classifier, with a prediction API and a web app for trying it out.

Features

- Trained XGBoost model on the credit card fraud dataset
- Feature scaling and a tuned decision threshold to handle the class imbalance
- REST API for predictions (`api/`)
- Interactive app for testing transactions (`app.py`)
- Sample transactions for quick demos (`samples.json`, generated by `make_samples.py`)

 Project Structure

```
fraud-detection/
├── api/                    Prediction API
├── models/                 Saved model, scaler, threshold, feature columns
├── app.py                  Web app
├── make_samples.py         Generates samples.json from the dataset
├── fraud_detection.ipynb   Data exploration and model training
├── samples.json            Example transactions
└── requirements.txt
```
Dataset

The dataset is not included in this repo because of its size.

1. Download the **Credit Card Fraud Detection** dataset from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
2. Create a `data/` folder in the project root.
3. Place the file at `data/creditcard.csv`.

Setup

```bash
 Clone the repo
git clone https://github.com/Jyothikav-tech/fraud-detection.git
cd fraud-detection

Create and activate a virtual environment (Windows PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1

Install dependencies
pip install -r requirements.txt
```

Usage

Run the web app:

```bash
streamlit run app.py
```

Run the API:

```bash
uvicorn api.main:app --reload
```

Then open `http://127.0.0.1:8000/docs` to try the API.

To regenerate sample transactions (requires the dataset):

```bash
python make_samples.py
```

 Model

- Algorithm: XGBoost
- Preprocessing:StandardScaler on the input features
- Imbalance handling:custom decision threshold instead of the default 0.5
- Training and evaluation steps are in `fraud_detection.ipynb`.

Tech Stack

Python, XGBoost, scikit-learn, pandas, FastAPI, Streamlit
